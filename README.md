# Modernisasi-Teknologi-Budidaya-Udang-Vaname-Berbasis-Arduino-UNO
Modernisasi teknologi budidaya udang vaname ini menggunakan sensor suhu dan sensor pH yang memungkinkan petani tambak udang untuk memantau dan mengendalikan sistem sehingga dapat mempermudah dan meningkatkan produktifitas dari hasil budidaya udang vaname.
